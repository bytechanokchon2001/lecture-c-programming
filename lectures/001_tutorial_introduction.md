# Tutorial Introduction
ทุก ๆ การครั้งที่เราจะเรียนเขียนโปรแกรมด้วยภาษาใหม่ เราจะเริ่มต้นด้วยการแสดงข้อความ `Hello World` ออกมาที่หน้าจอ โดยในภาษา c เราสามารถทำได้ด้วยคำสั่งดังนี้

    #include <stdio.h>              // นำเข้าไลบรารีอินพุต/เอาต์พุตมาตรฐาน

    int main()                      // สร้างฟังก์ชัน main โดยไม่รับอาร์กิวเมนต์ใด ๆ
    {
        printf("Hello World");      // เรียกใช้งานเมธอดของไลบรารี่เพื่อแสดงข้อความ Hello World

        return 0;                   // ส่งคืน 0 เพื่อบอกคอมไพเลอร์ว่าโปรแกรมทำงานจนจบ
    }

หลังจากนั้นเราสามารถคอมไพล์คำสั่งภาษา c ไปเป็นภาษาเครื่องได้ด้วยคำสั่ง `gcc hello.c` ผลลัพท์ไฟล์ `a.exe` จะถูกสร้างขึ้น ซึ่งจะเป็นชุดคำสั่งภาษา c ที่เราเขียนไว้และถูกแปลงเป็นคำสั่งที่ภาษาเครื่องเข้าใจ เราสามารถรันโปรแกรมของเราได้โดยการเรียกใช้ `a.exe` โดยผลลัพท์คือข้อความ `Hello World` จะถูกแสดงออกมาที่หน้าจอ

โปรแกรมภาษา c ไม่ว่าจะเป็นโปรแกรมขนาดเล็กหรือใหญ่ ก็จะประกอบด้วย ฟังก์ชัน ตัวแปร
- **ฟังก์ชัน:** จัดเก็บการดำเนินการกับข้อมูล
- **ตัวแปร:** จัดเก็บข้อมูล

### ฟังก์ชัน main()
จะเป็นฟังก์ชันที่พิเศษกว่าฟังก์ชันอื่น โดยเป็น**ฟังก์ชันแรกของโปรแกรมที่จะถูกเรียกใช้งาน** และทุก ๆ โปรแกรมภาษา c จะต้องมีฟังก์ชัน main 

โดยเราจะใช้ฟังก์ชัน main เพื่อเรียกใช้งานฟังก์ชันอื่น ๆ ในโปรแกรม โดยอาจเป็นฟังก์ชันที่เราเขียนขึ้นมาเอง หรือเป็นฟังก์ชันที่เรานำเข้ามาจาภายนอก

### #include<stdio.h>
เป็นคำสั่งที่บอกคอมไพเลอร์ว่า ให้นำชุดคำสั่งของ `stdio.h (ไลบรารีอินพุต/เอาต์พุตมาตรฐาน)` เข้ามาในโปรแกรมของเราด้วย เพื่อให้เราสามารถเรียกใช้งานได้ เช่น `printf()`

### การสื่อสารระหว่าง method
เราสามารถส่งข้อมูลให้กับเมธอดอื่น ๆ ได้ โดยข้อมูลที่เราส่งเข้าไปจะถูกเรียกว่า `อาร์กิวเมนต์ (arguments)` เช่น `sum(1,2);` โดย 1 และ 2 คืออาร์กิวเมนต์
